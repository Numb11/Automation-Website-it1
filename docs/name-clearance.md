# Limbert Lyons — name clearance

Checked on 6 November 2026. This is a search record, not a trade mark attorney's opinion and not a Companies House decision. The binding test is still the name you type into the incorporation form, and a trade mark application if you want to stop someone else trading under the same words.

**Limbert Lyons** is clear enough to put on the page and on a proposal. File the company as **LIMBERT LYONS LTD** only after the official availability checker accepts it. ## Trade marks

The Intellectual Property Office search site blocked an automated check with a security page, so this record does **not** clear the trade mark.

A public web search did not surface a registered mark for the phrase "Limbert Lyons". That is not a clearance. Before you apply, search the words yourself at [trademarks.ipo.gov.uk](https://trademarks.ipo.gov.uk/ipo-tmtext), exact match and similar match, in classes 42 (IT services) and 35 (business consultancy). A UK application starts from about £170 and the fee is not refunded if the mark is refused. A trade mark attorney is cheaper than a refused filing if the search shows anything close.

Registering the company does not give you a trade mark. A trade mark does not guarantee Companies House will accept the company name.
